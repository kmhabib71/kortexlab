## CLIENT ONBOARDING - MANUAL PROCESS

**Q: How many new clients per week?**
- 2-3 per week (8-10 per month target)

**Q: Who owns client onboarding?**
- Max, Lily, Amanda (Client Ops team)
- Whoever responds to contract email becomes that client's "Client Ops Owner" for entire journey

**Q: What's the onboarding workflow?**

**Step 1: Receive Contract (from TSQ)**
- PDF with contract price, billing terms, address

**Step 2: HubSpot Setup (Manual)**
- Find client's page in HubSpot
- Add LinkedIn URL (manual)
- Change client type to "Current Private Advisor Client"
- Add advisor name (Claire, David, Liv)
- Add transition pathway (Transition Services, Network Builder, etc.)
- Add contract start date
- Add kickoff call date
- Add billing terms
- **Problem:** Often don't know who the client is or where they came from - have to ask advisor

**Step 3: Notion Setup (Partially Automated)**
- Mark client as "Tier 1 Executive" in HubSpot
- **WhaleSync automatically creates Notion page** (this is automated!)
- Pre-populated with contract info
- **Still manual:** HubSpot link, Contender profile link
- All kickoff notes, deep dive background info goes here
- All docs tagged to client show up on this page

**Step 4: Welcome Email (Automated)**
- Send template email: "Welcome to Banff"
- Include kickoff form link
- Include calendar link for 60-90 min kickoff call

**Step 5: Contender Setup (Manual)**
- Create new executive profile from scratch if brand new
- Go to LinkedIn, download PDF resume
- Copy profile picture
- Enter basic info
- Upload PDF (parses automatically to look like LinkedIn)
- Change from Tier 3 to Tier 1
- Add advisor name (manual)
- Add kickoff date after call happens (manual)
- Add email address (manual)
- Add target functions, industries, operating roles (manual - filled out after kickoff call)

**Step 6: Google Drive Setup (Manual)**
- Create client folder in Google Drive
- Houses all narratives, resumes, LinkedIns, bios
- Does NOT live in Notion, HubSpot, or Contender

**Time estimate:** Not specified, but "annoying amount of time" per client

## SERVICING - MONTH 1-2 (STANDARDIZED)

**Q: What happens in the first 1-2 months?**

**This phase is very standardized and works well**

## ZOOM CALL TRACKING - BIGGEST PAIN POINT

**Q: How do Zoom transcripts work?**
- Zapier pulls Zoom transcripts into Notion automatically
- Creates page in "Banff Advisor Kickoff Full Transcripts" database
- Dumps word-for-word transcript

**Q: What's manual?**
1. **Tag to client profile** (unless you launch from client's page)
2. **Tag call type:** Kickoff, Check-in, Interview Prep, Personal Branding, Narrative Review
3. If not tagged correctly → **Retool alerting system breaks**

**Problems:**
- If 4-5 people are on calls at same time, multiple transcripts dump at once
- "Can get pretty messy" - 30-60 minutes to sort
- Human error: forget to tag or tag wrong type
- If call type not tagged → doesn't count in activity tracking

**Q: Do advisors have different workflows?**
- **YES - major inconsistency**
- David: Same workflow for years (launches from client page)
- Liv: Newer, different workflow
- Claire: Brand new, different workflow
- If advisor launches call from client page → auto-tags to profile
- If not → must manually tag

## RETOOL DASHBOARD - CLIENT PATHWAY MANAGEMENT

**Q: What is Retool used for?**
- Testing ground for workflows, ideas, reporting
- **Main use:** Client Pathway Management Dashboard

**Q: What does the dashboard track?**
- All 212 exec clients in one place
- Every client touchpoint/activity:
  - Advisor name
  - Contract start date
  - Contract week/month
  - All activities (Personal Branding calls, Interview Prep, Narrative Reviews, P2Ps, etc.)

**Q: How does alerting work?**
- If activity is tagged in Notion → automatically updates Retool
- Example: Tag call as "Interview Prep" → Retool marks Interview Prep = 1
- **Alerting system prompts:** "Client hasn't had X activity, set up a call"

**Problems:**
- **If call type not tagged correctly in Notion → reporting and alerting "all out of whack"**
- Human error breaks the entire system

## CONTENDER - PROFILE CREATION & UPDATES

**Q: How are Contender profiles created?**

**New Client:**
1. Add new executive client
2. Download LinkedIn PDF
3. Copy profile picture
4. Enter basic info
5. Upload PDF (auto-parses)
6. Make Tier 1
7. Add advisor, kickoff date, email, target functions/industries (all manual)

**Exec Growth (adding warm prospects):**
- Whole team adds people to Contender by talking to them
- "Manual labor bucket"
- Either upload PDF or use licensed data service to pull info in batches

**Q: What's the LinkedIn data issue?**
- Contender creates "pretend LinkedIn" profiles
- **Problem:** If someone updates real LinkedIn and Banff hasn't talked to them in 2 years → data is stale
- Must manually update or "we look like idiots"
- No API to LinkedIn
- Workaround: Upload PDF or use licensed data service

**Q: Is there bulk upload capability?**
- YES - created for a fund client who wanted to add 400 people
- Still manual aspects (industry, functional focus, tagging)
- Expecting more bulk uploads in 2026 for network management
