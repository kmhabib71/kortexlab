## Strategy for Success

### Week 1 Strategy
1. **Listen more than talk** in discovery calls
2. **Document everything** - create workflow diagrams
3. **Identify "quick wins"** - simple automations with big impact
4. **Map data flows** between all their systems

### Build Phase Strategy
1. Start with **lowest-risk, highest-impact** automations
2. Test thoroughly before deploying
3. Create **monitoring/logging** so you can prove time saved
4. Get feedback early and often

# Questions to Ask Matthew (Before Client Meeting)

## About the Client
1. What's Banff Advisors' main business? (Financial advisory?)
2. How many employees do they have?
3. What's their biggest pain point right now?
4. What's their budget/expectations for Phase 1?

## About Your Role
1. Am I leading technical discussions in client calls, or supporting you?
2. Do I have a budget for third-party tools (API costs, hosting)?
3. Who reviews my work before it goes to the client?
4. What's the communication rhythm? (Daily standups? Slack?)

## About Deliverables
1. Do you have existing templates/frameworks I should use?
2. What does "Current State Map + Build Roadmap" look like?
3. Where do I host the automations? (Client's infra or Kortex's?)
4. How do we measure "hours saved" - client self-report?

## Technical Questions
1. Have you worked with this client's tech stack before?
2. Any known API limitations or issues with their systems?
3. Do they have a developer on their team I'll coordinate with?

# How to Prepare for the Meeting

## Before the Meeting
- [ ] Review HubSpot API docs (especially Deals, Contacts, Workflows)
- [ ] Review Notion API docs
- [ ] Watch Retool tutorials if unfamiliar
- [ ] Prepare a notepad/doc to capture client workflows live
- [ ] Have questions ready for each department (Sales, Ops, Dev, Marketing, Finance)

## During the Meeting
- [ ] Take detailed notes on manual processes mentioned
- [ ] Ask "how long does that take?" for every manual task
- [ ] Ask "what happens when it goes wrong?"
- [ ] Identify data that moves between systems manually
- [ ] Note any integrations they wish they had

## After the Meeting
- [ ] Create workflow diagrams from notes
- [ ] Estimate hours for each automation
- [ ] Prioritize by impact vs effort
- [ ] Draft Week 1 deliverables outline

- Client expectations exceeding 6-week timeline
- Dependencies on client team responses
